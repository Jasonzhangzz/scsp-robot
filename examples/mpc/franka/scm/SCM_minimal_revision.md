# SCM 的最小修改建议及验证范围

当前证据支持保留时变对角 Delassus 近似、闭式反作用和冻结几何下的分段仿射结构，
增加有限接触恢复时间。原来的逐行完整恢复是这一新模型的极限情形。
本文件是模型与论文修改建议；尚未替换 tro_revision 中的准动态 CSO 公式。

## 1. 方向与幅值

原实验 sliding 中，SCM 接触速度修正与 MJWarp 的惯性加权夹角为 11.59°，
全部 500 样本小于 90°；总速度增量夹角约 20.39°。
幅值校正保持接触修正方向不变，主要减小过强的反作用。
sticking 参考增量很小时，方向角可能很大且敏感，不能据此判定接触力反向。
一步恢复和接触解耦可能同时引起幅值及分量比例误差，尚未通过分项消融证明全部误差的因果来源。

## 2. 修改的接触律（全动态基准的冲量单位）

令 D=diag(J M^-1 J.T)+rI，v_free 为无接触动力学预测，p 为非负棱锥面冲量。
将原式

```text
p = max(-D^-1 (J v_free + phi/h), 0)
```

替换为

```text
x = h/tau
a = (2*zeta*x + x*x)/(1 + 2*zeta*x + x*x)
b = x*x/(1 + 2*zeta*x + x*x)
p = max(-D^-1 (a J v_free + b phi/h), 0)
v_next = v_free + M^-1 J.T p
```

tau>0 是全局响应时间，zeta>0 是全局阻尼比。仍逐步更新 D，既不采用 ComFree 的 gap-dependent
先验阻抗，也不使用额外幅值投影或内层优化。tau→0 时 a,b→1，恢复原 SCM。

取每个独立行的有效质量 m_i=1/D_i、刚度 k_i=m_i/tau²、阻尼 d_i=2*zeta*m_i/tau。
在该行的解耦近似下，隐式离散为

```text
u_next = u + p/m_i
y_next = phi + h*u_next
p = -h*(k_i*y_next + d_i*u_next)
```

解这一标量方程并进行单边非负截断，直接得到上述 a,b。
这解释了有限恢复速度的机械来源；整个多接触系统仍使用近似耦合，不能由此宣称全局能量稳定性。
全局刚体积分仍为共同基准的 Euler，不等于改用一个完整隐式积分器。

当 h→0 时，p/h 趋近有限的逐行 spring–damper force：

```text
max(-D^-1 [(2*zeta/tau) J v_free + phi/tau²], 0)
```

因此 gap/h 不再独立导致随缩小步长而无限增强的恢复力。

## 3. 对优化与论文的影响

冻结 J、phi、M、D、h、tau、zeta 后，a,b 为常数；v_free 对输入力仿射时，
硬 max 版本仍分段仿射。用论文已有 SoftPlus 代替 max 后，接触项的梯度只需链式法则，
无幅值投影系数的额外导数。硬 max 固定激活分支下的局部力雅可比已与 GPU 有限差分核对。
该验证不代表整个 CSO、接触集变化或 SoftPlus 闭环优化都已验证。

最少需要改动：

1. 接触反作用公式中分别对运动项和间隙项加入 a,b，并说明 tau、zeta 的选择。
2. 机械解释改为有限时间恢复的解耦 spring–damper 近似，保留对角近似的来源。
3. 冻结系数的显式性、分段仿射/SoftPlus 梯度结论保留，公式相应加入系数。
4. 误差 lemma 加入软化带来的残差；不能原样把新模型当成原来的对角 QP 解。

例如令原匹配参考的 W、g 不变，新模型的 g_soft=a J v_free+b phi/h、E=W-D。
在 W 正定和硬 max 条件下，可以由两个非负 QP 的变分不等式得到

```text
||p_soft-p_ref|| <= ||E p_soft + g-g_soft|| / lambda_min(W).
```

这是条件误差判据，不是多数状态准确的无条件证明。运动误差和 task-descent 条件再由这一残差推进。
也可以另定义与软化接触目标匹配的耦合参考；此时必须明确参考模型已改变。

论文原准动态单位、epsilon 与 h 缩放、状态更新，以及三分量力和四面非负乘子的表述，
仍需和实际 CSO 实现逐项对齐。本次全动态四面基准不能直接替代这些检查。
该方法属于受 ComFree 启发的 surrogate 扩展，应保留相关引用，不能把 spring–damper 思路称为全新机制。

## 4. 数据与结论

用原 seed=42 的 1000 个 sliding/sticking 输入，在预先定义的 72 组网格上校准两个全局参数，
目标为平均惯性加权速度误差。选出 tau=.008 s、zeta=.25；未用验证输入选参数。
这属于对数值参考的参数校准，不应描述为完全无数据调参。

新 seed=20261009、五形状各模式 100 输入、共 1500 输入的实际 GPU 验证：

| 模式/误差 | ComFree 当前参数 | 原 SCM | 幅值校正 SCM | 有限恢复 SCM |
|---|---:|---:|---:|---:|
| sliding 线速度 (m/s) | 0.0593±0.0218 | 0.3794±0.1833 | 0.2208±0.0929 | 0.0154±0.0107 |
| sliding 角速度 (rad/s) | 1.0113±0.7414 | 5.7592±3.2489 | 3.6170±2.2004 | 0.5372±0.3306 |
| sticking 线速度 (m/s) | 0.0177±0.0011 | 0.0914±0.0166 | 0.0244±0.0118 | 0.0082±0.0019 |
| sticking 角速度 (rad/s) | 0.0103±0.0117 | 0.0148±0.0182 | 0.0096±0.0058 | 0.0104±0.0091 |

每行 n=500；mean±std、std 为总体标准差，reference 为固定版本 MJWarp。
separation 各模型基本一致。这里对比的是既有 ComFree (k,d)=(.1,.001)，并未等预算重新优化其参数。

保持这两个参数不变，在 mu=.2/.8、h=.001/.004 的新输入中完成 17 个配置、2550 输入。
四个非胶囊形状的四组组合全部完成，胶囊仅 mu=.2,h=.001 完成。
其他胶囊配置因参考静止准备失败/批处理中止未评估，失败日志和配置列表保留在 manifest.json。
合并 sliding/sticking 线速度误差分别约为当前 ComFree 的 .294/.368 倍，惯性加权误差为 .361/.370 倍。
但高摩擦 sticking 的角速度误差更大（mu=.8,h=.004 均值为 ComFree 的约1.47倍）。
因此不能称为所有模式/指标全面优于 ComFree。

连续滑动 1000 步 h=.002：新模型趋于静止，终态动能约5.73e-8 J。
物体位置轨迹相对 MJWarp 的 RMSE 为 .0742 m，ComFree 为 .0956 m，幅值校正 SCM 为 .1332 m。
这只是一个滑动场景，尚未覆盖大规模堆叠、机器人接触和 CSO guidance 的闭环表现。

可支持的表述是：这一小改动在当前独立输入及部分跨参数测试中达到或超过现有 ComFree 基线的主要运动指标，
同时保留闭式和局部优化结构；是否适合论文的准动态 CSO，仍需对应的实现与 guidance 实验。

原始数据、mean±std 表、成对误差与输入相等检查分别位于：
`outputs/soft_scm_holdout/`、`outputs/soft_scm_parameter_holdout/`；
训练记录在 `outputs/soft_scm_calibration/`；连续轨迹在 `outputs/sliding_soft_scm/`。
