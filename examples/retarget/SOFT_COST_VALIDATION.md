# 软手形与 trigrasp 在线代价

这是软手形改造阶段的记录；其中净 wrench 跟踪和预载覆盖控制已按最新要求撤除。
当前实现见 [CONTACT_POSE_MPC_VALIDATION.md](CONTACT_POSE_MPC_VALIDATION.md)。

本次修改移除了几何 IK 和接触候选验证中的 25 mm 手形误差硬拒绝。
每个有效 MANO 帧仍单独求解几何 IK，并持续提供该帧 `wuji_q`；手形、
原始手部材料点、物体语义锚点和区域法向通过软代价共同优化。
关节限位、碰撞和接触候选的物理可达性检查仍保留。

## MPC 代价

对应 `trigrasp.py` 在线控制器和 `planning/allegro_mpc_costs.py` 的结构：

| 项 | 默认配置 | 行为 |
|---|---:|---|
| 物体横向 / 高度 | 300 / 120 | 跟踪当前局部轨迹目标 |
| 物体旋转 | 50 | `50/8 * ||R_goal.T R - I||²` |
| 执行接触点 | 5000 | 对齐随物体运动的材料点；建立接触后释放法向深度 |
| 原始语义接触 | 150 | 原始手部材料点与 MANO 物体锚点的软对应 |
| 区域法向 | 0.1 | 鼓励原始区域朝向 |
| 横向软走廊 | 2e6，宽度 ±5 mm | 抑制未抓稳时把物体推走；越界增加代价，不拒绝方案 |
| 接触运输 | 1000 | 以实际承载证书启用有界物体目标方向运输 |
| 净 wrench | 10 | 力除以物体重量；力矩再除以 5 cm |
| 腕部位置 / 旋转 / 手指姿态 | 1 / 0.5 / 5 | 跟踪每帧几何 IK，接触附近保留至少 0.05 倍权重 |
| 平移 / 旋转 / 关节动作 | 0.03 / 50 / 50 | 位置伺服目标增量的正则化 |
| 终端任务 | 4 倍 | 保留物体、接触及碰撞任务，不强制恢复手形或伺服深度 |

与原在线 trigrasp 的区别是：Wuji 始终保留非零手形软权重，以满足逐帧
retarget 跟踪；还保留原始 MANO 材料点和语义锚点的软目标。
`default.yaml` 的 `mpc_costs` 可覆盖权重；每次运行保存完整 `mpc_costs.json`。

## 实际接触与预载

- 示教接触 mask 与实际接触集合分开维护。Lambda 不可行或参考释放时，
  真实接触仍参与 SCM、材料点保持、力分配和实测预载反馈。
- 使用 trigrasp 的共享 live wrench allocator 请求承载力；桌面支撑不从
  抬升请求中扣除，也不把当前很小的实测法向力当作未来预载上限。
- 已建立的手部材料点保持其物体坐标，直到分离或材料点重映射。
  滑移不会逐周期重置该软目标。
- 预载反馈和 SCM 使用同一实际接触位置的 Jacobian；语义材料点 Jacobian
  仅用于其自身的软跟踪，避免沿指节偏移后产生错误的压入运动。
- Lambda 摩擦锥、力限和原始方案优先逻辑保持不变。闭合不是 Lambda 的
  硬可行性门槛；物体仍仅由实际手部接触驱动。

## 检查

相关单元和集成测试 **102 passed**。新增/更新检查覆盖：大手形偏差不会
拒绝几何 IK；接触时手形目标非零且可减弱；终端目标不会锁住伺服深度；
trigrasp 物体权重及软走廊数值；Lambda 失败和参考释放后保留实测接触；
未来预载不受当前微小接触力冻结；滑移不重置已建立材料点；预载与 SCM
法向 Jacobian 一致；wrench 力矩原点不随输出线性化重置。
