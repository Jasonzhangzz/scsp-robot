启动 IK 拒绝与上一版对照（2026-10-14）

HEAD 的 online IK 已使用平均误差 2 mm、最大误差 3 mm、自碰撞穿透 0.1 mm 的验收门槛，本次没有新增这些限制。此前成功运行的实际 IK 误差为 1.6296 / 2.0596 mm，自碰撞穿透为 0。用户报错的 2.7 / 4.1 mm 同时超出前两项门槛；原来以米保留四位小数的穿透输出不足以区分是否超过 0.1 mm。

确认了旧版单个 IK 迭代的选择错误：求解器按综合分数保存历史最优，然后在当前迭代达到可行门槛时退出，但返回值仍可能是更早、分数更低的不合格迭代。现在先比较可行性，再比较分数。新增测试用可行但总分更高的迭代复现这个错误。尚未获得用户失败运行的完整搜索轨迹，不能断言该错误就是那次异常的唯一原因。

NoSlip 曾在启动静置中参与计算，改变物体的初始位姿：对照中 x 约变化 0.241 mm，姿态也有变化。这会改变 Lambda/IK 的输入，但不是上述异常的直接因果证明。现在初始化静置保持 NoSlip=0，构造完成后恢复配置的 NoSlip 次数；抓取执行仍使用默认 3 次。新增真实场景测试确认配置为 0 / 3 时初始物体位姿一致，而执行模型分别恢复到 0 / 3。

曾测试将 online IK 门槛放宽至 4 / 6 mm，虽然启动成功，但较早接受 3.557 / 4.496 mm 的较差种子，400 步内未抓取成功（ik_seed_fix.json）。该放宽已经撤回，保留原来 2 / 3 mm 门槛。新的错误日志会明确列出 blocked_by、检查的候选组数、预算是否耗尽和各项精确阈值。
