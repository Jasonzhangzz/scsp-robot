# Ranking-strategy counterfactual evaluation (Table VI)

Run in the IsaacGym/acados environment from the repository root. Defaults are
one successful source trajectory per object/task, 5 distinct uniformly sampled
eligible physical-contact decision timestamps (excluding transit), one opposite rollout per timestamp, and gamma=0.99.
Both rotation and flipping use all stages unless `--rs-event-stage flip` is set.

```bash
python test_rs.py --obj foam_brick --rotation --trial_num 10 \
  --rs-output outputs/rs_rotation

python examples/mpc/franka/experiments/ik2/run_rs_cohort.py \
  --output outputs/rs_table_vi_new \
  --source-csv output/benchmarks/current_mpc_async_7x3_20261016/trials.csv \
               outputs/isaac_five_trials_20261012/trial_statistics.csv
```

The cohort covers the seven standard objects in both tasks. Each case runs in
an isolated process. CSV summaries identify historically successful seeds; they
do not contain simulator or controller checkpoints. Seeds are randomly ordered
with `--sample-seed` (default 0). The current synchronous factual source is first
reconstructed and checked for success. The first successful reconstruction with
at least 5 eligible decisions is selected; short or failed reconstructions are
recorded and skipped. If none qualifies, that case fails explicitly. Historical
asynchronous completion times are never used as paired factual values.

`--rs-source-cache` accepts a trusted local complete cache generated by
`test_mpc_isaac.py --headless --sync-planner --trial_num 1 --rollout-cache-dir DIR`.
It must match the current configuration and prefix. Old-version caches may be
incompatible; do not weaken matching to make them pass.

A sample requires distinct contact patches (over 3 cm geodesic distance with
Euclidean fallback), a nearby/observed contact, and a feasible alternative target.
Sampling requires measured physical contact (`if_contact` or a nonpositive measured contact gap), and excludes blocked detour/transit states. Proximity alone does not qualify.
Sampling is without replacement across eligible contact decisions, including
stable near selections. It is not limited to switching onsets or best-point
changes. Fewer than 5 candidates does not silently produce a smaller dataset.
The older event-stratified mode is available with `--rs-sampling events` and
`--rs-max-per-kind`; it is not used for Table VI.

For each sample, the factual value comes from the original successful suffix.
The opposite branch reconstructs the full prefix from the same trial seed,
including simulator/controller history and solver warm starts. Observations,
velocities, contact geometry, commands, and ranking decisions are checked before
the intervention (`--rs-match-atol 1e-7`, zero relative tolerance). A mismatch
aborts the case. At the sampled decision the nearby/CSO contact commitment is
swapped before CPO and MPC; all later decisions use normal replanning. Contact
normals, cached predictions, and approach state follow the forced target. This
is a binary choice swap, not coordinate negation.

```text
V = 0.99 ** remaining_control_steps * success
A = V_RS - V_opposite
```

The chosen action counts as the first remaining 20 ms control step. Failed
branches have zero value. Both branches keep the same absolute task deadline.
All sampled points, including A=0, enter P(A>0) and mean ± sample std (ddof=1).
`--rs-repeats` repeats both branches with identical seeds; these are not
independent stochastic observations.

Seven Table VI quantities are exported:

| Key | Definition |
| --- | --- |
| `contact_switch_count` | Total completed physical relocations across selected original trajectories. |
| `p_near` | Near selections / all eligible binary decisions in the full sources. |
| `p_optimal` | Optimal selections / the same denominator. |
| `f_near_hz` | Near selections / total source simulated seconds. |
| `f_p_star_hz` | CSO argmin patch changes / total source simulated seconds. |
| `p_advantage_positive` | Count(A>0) / all sampled points. |
| `advantage` | A mean and sample standard deviation. |

The p-star counter compares object-local argmin positions against the last
counted anchor, with `--rs-best-change-distance` (default 1 cm). The first point
is excluded. Object translation/rotation alone cannot count as a patch switch.
Physical contact switches are measured independently from the complete executed
contact trace: a far MPC target, loss of measured contact for at least two control
observations, then three stable contact observations on a distinct patch (3 cm)
at the new target (2 cm arrival tolerance). Initial contact, sliding, mesh-index
jitter, and unsuccessful travel do not count.

Per-case output includes `config.json`, `trials.jsonl`, the source replay cache,
complete contact and ranking traces, `states.jsonl`/`states.csv`, `summary.json`,
and `table_vi.csv`. State rows store both world-space target choices, factual
and perturbed values, outcomes, and A. Failed/short source attempts are excluded
from all seven metrics. Frequencies use full selected original trajectories,
never the 5-point sample or counterfactual branches. Missing measurements are
null, not zero. Results are flushed after each pair. `--rs-resume` validates the
configuration and reconstructed source before reusing completed pairs.

The cohort writes `manifest.json` with commands, source hashes, provenance, and
case statuses, plus task-level `summary.json`, `table_vi.csv`, and
`table_vi_rows.tex`. Only when every case completes does it fill the two rows of
`tro_revision/experiment.tex` Table VI (`--no-update-paper` disables this).
An incomplete cohort remains labelled incomplete and does not populate the paper.
